Guia de formulas
Como funciona
  1. Cree una hoja de calculo con el boton + de las pestanas (o Formulas > Nueva hoja de calculo). Las hojas de datos son de solo lectura.
  2. Escriba = en una celda: al teclear aparece el autocompletar. Flechas para moverse, Tab o Enter para aceptar, Esc para cerrar.
  3. Dentro de las comillas de BUSCARVISTA el autocompletar sugiere primero las vistas cargadas y luego las columnas de esa vista.
  4. El resultado aparece en la misma celda donde escribe la formula.

Separador de argumentos: ; (punto y coma), igual que Excel en espanol. Decimales con coma: 1,5.
